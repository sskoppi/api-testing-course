# Модуль 5. Приложение на tkinter

## Что сделано
- `models.py` — модель пользователей (список-заглушка + функции)
- `app.py` — интерфейс: экран входа, капча, админ-панель, изменение, добавление
- `captcha_real/` — 4 фрагмента капчи

## Самостоятельные задания
1. Цвета изменены: BG = #f0e6f5, FIELD_BG = #9999ff, FIELD_FG = #22262b
2. Шрифты: FONT_TITLE = Georgia 20 bold, FONT_LABEL = Arial 12, FONT_BUTTON = Verdana 14 bold
3. Курсив: надпись над капчей — italic; заголовок экрана входа — bold italic
