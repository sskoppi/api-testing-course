## Json2. Пять ошибок

1) `{ 'name': "Анна" }` → ошибка: ключ в одинарных кавычках → исправлено: `{ "name": "Анна" }`
2) `{ name: "Анна" }` → ошибка: ключ без кавычек → исправлено: `{ "name": "Анна" }`
3) `{ "a": 1, "b": 2, }` → ошибка: лишняя запятая в конце → исправлено: `{ "a": 1, "b": 2 }`
4) `{ "a": 1 "b": 2 }` → ошибка: нет запятой между парами → исправлено: `{ "a": 1, "b": 2 }`
5) `{ "a": "незакрытая` → ошибка: строка и объект не закрыты → исправлено: `{ "a": "незакрытая" }`

## Json6. Пять фрагментов

1) `{ "a": 1, "b": "2" ]` → ошибка: закрыто `]` вместо `}` → исправлено: `{ "a": 1, "b": "2" }`
2) `{ "a": 1; "b": 2 }` → ошибка: `;` вместо `,` → исправлено: `{ "a": 1, "b": 2 }`
3) `[1, 2, 3` → ошибка: массив не закрыт → исправлено: `[1, 2, 3]`
4) `{ "a": True }` → ошибка: True с большой буквы → исправлено: `{ "a": true }`
5) `{ "a": "x", "b": undefined }` → ошибка: undefined не валидное значение → исправлено: `{ "a": "x", "b": null }`

## Json8. GET /html

- Статус: 200 OK
- Content-Type: text/html; charset=utf-8
- Первые два тега: `<!DOCTYPE html>`, `<html>`
- JSON ли это: нет
- Признак 1: заголовок Content-Type = text/html
- Признак 2: тело начинается с `<`, а не с `{` или `[`


## Json9. POST httpbin — raw JSON vs form

**Запрос 1 (raw JSON):**
- Content-Type запроса: application/json
- json в ответе: {"title": "T", "userId": "1"}
- form в ответе: {}

**Запрос 2 (form-urlencoded):**
- Content-Type запроса: application/x-www-form-urlencoded
- json в ответе: null
- form в ответе: {"title": "T", "userId": "1"}

**Вывод:** сервер читает тело по заголовку Content-Type — не по содержимому.

## Json11. Переводы форматов

**XML → JSON:**

```json
{
  "id": 5,
  "done": true,
  "title": "Купить хлеб",
  "tags": ["еда", "срочно"]
}
```

Решение по типам: id → число, done → булево.

**JSON → XML:**

```xml
<?xml version="1.0" encoding="UTF-8"?>
<location>
  <city>Казань</city>
  <metros>
    <metro>Кремлёвская</metro>
    <metro>Суконная</metro>
  </metros>
</location>
```

Решение по city: тег (это значение ресурса, а не идентификатор).

Валидатор про JSON: Valid JSON.
