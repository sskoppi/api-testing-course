## Json2. Пять ошибок

1) `{ 'name': "Анна" }` → ошибка: ключ в одинарных кавычках → исправлено: `{ "name": "Анна" }`
2) `{ name: "Анна" }` → ошибка: ключ без кавычек → исправлено: `{ "name": "Анна" }`
3) `{ "a": 1, "b": 2, }` → ошибка: лишняя запятая в конце → исправлено: `{ "a": 1, "b": 2 }`
4) `{ "a": 1 "b": 2 }` → ошибка: нет запятой между парами → исправлено: `{ "a": 1, "b": 2 }`
5) `{ "a": "незакрытая` → ошибка: строка и объект не закрыты → исправлено: `{ "a": "незакрытая" }`
